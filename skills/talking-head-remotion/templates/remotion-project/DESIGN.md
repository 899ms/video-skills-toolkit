# __PROJECT_TITLE__ 设计说明

## 风格

乳白瓦楞玻璃 · Studio 口播视频主题。口播决定时间线，画面只承载关键词、数字、证据截图、短对比和 CTA 短句。

视觉目标：冷调乳白全画幅画布、两侧竖向瓦楞玻璃棱线、透过玻璃渗出的暖桃色光、pastel 淡紫/冰蓝呼吸、石板蓝黑大字、克制长春花蓝点缀、珊瑚橙前景暖强调、大留白、磨砂玻璃悬浮层、右下角圆形口播 PIP、底部磨砂玻璃药丸字幕。冷白与暖橙的对比是整套体系的灵魂。

## 必须满足的布局

- 1920x1080 / 30fps。
- 顶栏是悬浮磨砂玻璃胶囊：`top:18px; left/right:28px`，全圆角，冷调阴影；墨色 `ink` 圆角进度填充。
- 顶部章节名在等宽章节格中心，进度填充扫过文字时用双层 mask（未播章节文字 `ink/muted`，进度填充内文字白色），填充层轨道宽度 = `1920-56`，不允许半个字被进度填充吃掉；白色进度填充从 `0%` 起步按真实时间推进。
- 舞台底色：接近 `#f4f4f7`，使用全画幅 `FlutedGlassBackground`。
- 背景 `FlutedGlassBackground` 必须包含全部六层：乳白渐变 + 四角 lilac/ice-blue 呼吸、两团暖桃光团、左右竖向瓦楞玻璃棱线（两侧反向流动）、高光扫带、漂浮光斑、中央帷幕 + 噪点。缺层视为失败。背景自带三层持续动效（棱线流动 / 扫光带 / 漂浮光斑），是"任一时刻至少一层在动"的兜底。
- 不要透视网格、纯白/灰色/暗色赛博背景、普通平面网格；不要把内容包进白色圆角卡片、缩小画板、网页 preview 容器或 dashboard shell（悬浮的是元素，不是画布）。
- 右下角圆形口播 PIP，要看到头和肩膀；默认 206px，白玻璃包边 7px，上下轻浮动（约 4 秒周期），阴影随浮动反向缩放。不要把整张原片缩小塞进圆里，也不要只裁脸。
- 底部居中的磨砂玻璃药丸字幕（底部 96px）；用长春花蓝 `accent` 加粗强调一两个关键词。
- 主画面只用关键词、列表、数字、对比、截图、录屏作为证据面。

## 设计变量

- 画布：`#f4f4f7`（乳白冷调）
- 主文字：`#1f2430`（石板蓝黑）
- 弱文字：`#7a7f8e`（冷灰）
- 弱数字：`#b8bcc8`
- 细线：`rgba(31,36,48,0.10)`
- 强调蓝：`#5b6cff`（柔和长春花蓝）
- 前景暖橙：`#f07a4a`（柔和珊瑚橙，章节数字/标记/徽章）
- 背景暖光：`glow rgba(255,152,92,0.52)`、`lilac rgba(196,186,238,0.22)`、`iceBlue rgba(168,196,236,0.20)`（只用于背景层）
- 顶栏：`rgba(252,252,254,0.86)`（磨砂浅玻璃胶囊）
- 磨砂玻璃卡：`glass rgba(255,255,255,0.66)` + `glassBorder rgba(255,255,255,0.85)`
- 深色代码卡：`#1b1f2a`（体系内唯一深色，做对比锚点）
- 字幕文字：`#1f2430`（磨砂玻璃药丸底）
- 字幕强调关键词：`#5b6cff`（加粗）
- 悬浮层冷调阴影统一：`rgba(31,38,68,…)`

## 字体

脚手架会从 `public/assets/fonts` 嵌入当前模板字体：

- 中文：`Noto Sans SC`
- 英文/数字：`Space Grotesk`

除非用户明确换主题，不要换成系统字体兜底。

## 模板检查

- 匹配当前 Studio 模板空间系统：内容安全区 `top:196px; left/right:120px; bottom:196px`，68px 顶栏（悬浮胶囊内高约 54px），206px PIP 放在 `right:104px; bottom:150px`，字幕底部 `96px`。
- PIP 开渲染前要抽开头、中段、动作明显处 3 帧校准：脸在圆心附近，肩膀可见，白玻璃包边完整，无黑边和大块无关背景。
- `FlutedGlassBackground` 要实际渲染全部六层：乳白渐变 + 角落呼吸、暖桃光团、竖向瓦楞棱线（两侧反向流动）、高光扫带、漂浮光斑、中央帷幕 + 噪点。缺任一层视为失败。
- 所有悬浮物（卡片/顶栏/PIP/字幕）一律圆角 + 冷调阴影 `rgba(31,38,68,…)`；深浅卡阴影强度分级。
- 主画面只放关键词。完整口播句子只放字幕。
- 动画由 Remotion 帧驱动，不使用 CSS animation 或 CSS transition。
